# 모듈 9: 자율주행 경로 탐색 기반 구축 (Navigation Setup)

이 문서는 모듈 8에서 예쁘게 생성한 2D 지도(`logistics_map.yaml`)를 바탕으로, 로봇이 맵 상에서 자신의 위치를 파악(AMCL)하고 목적지까지 장애물을 요리조리 피해 이동(move_base)하는 **Navigation 스택 연동 과정**을 다룹니다.

---

## 1. 개요
* **핵심 패키지**: `turtlebot3_navigation`
* **목표**: 파이썬 코드(비전 인식기 등)의 개입 없이, 오직 ROS 주행 패키지만으로 맵 내 자율주행이 정상 작동하는지(장애물 회피 등)를 검증합니다.

---

## 2. Navigation 스택 가동 및 초기 위치 설정

이전 매핑 작업에서 켜두었던 터미널(SLAM, Teleop 등)이 있다면 **반드시 모두 종료(`Ctrl+C`)한 뒤 깨끗한 상태에서 시작**합니다. 총 2개의 터미널이 필요합니다.

### [터미널 1] 시뮬레이션 (Gazebo) 실행
항상 그렇듯 물류 창고 맵과 로봇을 가장 먼저 띄웁니다.
```bash
roslaunch qr_logistics_robot logistics_world.launch
```

### [터미널 2] Navigation 노드 실행 (지도 불러오기)
모듈 8에서 저장해둔 맵 파일의 경로를 지정하여 주행 서버를 켭니다. (RViz가 자동으로 열립니다.)
```bash
roslaunch turtlebot3_navigation turtlebot3_navigation.launch map_file:=$HOME/catkin_ws/src/qr_logistics_robot/maps/logistics_map.yaml
```

### 📍 RViz에서 초기 위치 잡아주기 (2D Pose Estimate)
Navigation이 켜지면 로봇은 방금 불러온 지도상의 어디에 자기가 서 있는지 전혀 모릅니다. 우리가 직접 초기 위치를 알려주어야 합니다.
1. RViz 상단 메뉴바에 있는 초록색 화살표 **`2D Pose Estimate`** 버튼을 클릭합니다.
2. RViz 지도상에서 로봇이 현재 있는 실제 위치(중앙 원기둥 왼쪽 근처)를 **클릭한 채로 로봇이 바라보는 방향(오른쪽)으로 마우스를 드래그**하여 놓습니다.
3. 로봇 주위로 레이저 스캔 점(빨간색/초록색 점)들이 지도의 검은색 벽면과 일치하게 딱 맞아떨어지면 로봇이 자신의 위치를 깨달은 것입니다! (AMCL 성공)
*(만약 벽과 레이저 점이 어긋나 있다면 `2D Pose Estimate`를 다시 여러 번 시도해 딱 맞춰주세요.)*

---

## 3. 자율주행 수동 테스트 (Nav Goal)

이제 로봇이 스스로 길을 찾아갈 수 있는지 테스트해 보겠습니다.

1. RViz 상단 메뉴바의 보라색 화살표 **`2D Nav Goal`** 버튼을 클릭합니다.
2. 지도상에서 배송 목적지(오른쪽 위 또는 아래 구석)를 **클릭하고 로봇이 최종적으로 바라볼 방향으로 드래그**합니다.
3. **결과 확인**:
   - 클릭하는 순간 로봇부터 목적지까지 **초록색 얇은 선(Global Path, 전체 경로)**이 그려집니다.
   - 로봇 앞부분에 **파란색 선(Local Path, 실시간 장애물 회피 경로)**이 꿈틀대며 로봇이 스스로 바퀴를 굴려 이동합니다.
   - 맵 중앙의 장애물들을 부딪치지 않고 자연스럽게 피해 목적지에 예쁘게 정차하는지 감상합니다.

### ✅ 체크포인트 2 (성공 기준)
마우스 클릭만으로 로봇이 벽이나 장애물을 치지 않고 목적지까지 안전하게 자율주행을 완료한다면 완벽하게 성공입니다! 
이 테스트가 끝나면 **터미널 1과 2를 절대 끄지 마시고 그대로 둔 상태로** 알려주세요. 곧바로 마지막 모듈인 'QR 인식 통합 자동 주행 테스트'로 넘어가겠습니다!
