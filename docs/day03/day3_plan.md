# 3일차 (Day 3) 세부 진행 계획: 자율주행(Navigation) 완성 및 DB 연동

## 1. 개요
* **목표**: 2일차에 완성한 '데이터 통신 뼈대'에 실제 로봇의 자율주행 능력을 부여하고, 모든 배송 과정을 기록할 수 있는 데이터베이스(DB)를 연동합니다.
* **핵심 방향**: 단계별 디버깅과 시스템 안정성 확보를 위해 매핑(SLAM), 주행 서버 세팅(Navigation), 통합 이동 로직(Integration)을 각각 분리하여 검증합니다.

---

## 2. 모듈별 상세 계획

### [모듈 8] 2D 정밀 지도 생성 (Mapping / SLAM)
* **목표**: 로봇의 센서(LiDAR)를 활용해 현재 시뮬레이션 환경의 2D 격자 지도를 그립니다.
* **세부 작업**:
  1. `turtlebot3_slam` 패키지를 가동합니다.
  2. 로봇을 키보드로 수동 조종하여 맵 전체 구역을 꼼꼼하게 스캔합니다.
  3. 스캔이 완료된 지도를 `map_saver` 노드를 통해 `logistics_map.yaml` 및 `.pgm` 파일로 저장합니다.
* **검증 (체크포인트 1)**: 저장된 맵 이미지(`logistics_map.pgm`)를 열었을 때, 벽과 장애물 모양이 뚜렷한 흑백 지도로 잘 저장되었는지 확인합니다.

### [모듈 9] 자율주행 경로 탐색 기반 구축 (Navigation Setup)
* **목표**: 생성된 지도를 바탕으로 로봇의 현재 위치를 파악하고 장애물을 회피하는 주행 서버를 세팅합니다.
* **세부 작업**:
  1. 저장된 맵 파일과 함께 `turtlebot3_navigation` 노드(AMCL, move_base)를 가동합니다.
  2. RViz 상에서 `2D Pose Estimate` 기능을 사용해 로봇의 초기 위치를 맞춰줍니다.
  3. 파이썬 코드 연동 없이, RViz의 `2D Nav Goal` 버튼으로 맵 상의 임의의 지점을 클릭하여 로봇이 장애물을 스스로 피해 이동하는지 테스트합니다.
* **검증 (체크포인트 2)**: 파이썬 코드 개입 없이 순수 ROS Navigation 스택만으로 주행과 장애물 회피가 정상적으로 동작하는지 확인합니다.

### [모듈 10] QR 연동 기반 자율 이동 로직 통합 (Movement Logic)
* **목표**: 2일차에 만든 비전/경로 노드와 3일차의 네비게이션 스택을 결합하여, "QR 포착 ➡️ 자율 이동" 전체 시나리오를 완성합니다.
* **세부 작업**:
  1. 모듈 9의 Navigation이 켜져 있는 상태에서, 2일차의 `vision_recognizer_node`와 `path_planner_node`를 실행합니다.
  2. 로봇의 카메라 시야에 QR 박스가 들어오도록 조종합니다.
  3. 경로 탐색 노드가 파싱된 목적지 좌표를 `move_base` 서버로 하달하여 자율주행을 트리거합니다.
* **검증 (체크포인트 3)**: QR 코드가 카메라에 인식되는 순간, 수동 조작(Nav Goal) 없이도 로봇이 자동으로 목적지(A구역 등)를 향해 출발하고 정확히 정차하는지 확인합니다.

### [모듈 11] 배송 이력 관리 시스템 (Database 연동)
* **목표**: 로봇이 어떤 물건을 언제 어디로 배송했는지 기록하는 영구 저장소를 구축합니다.
* **세부 작업**:
  1. 우분투 환경에 SQLite3(또는 MariaDB)를 세팅합니다.
  2. `delivery_history` 테이블을 생성합니다. (기록 내용: `item_id`, `destination`, `status(배송중/완료)`, `timestamp`)
  3. `path_planner_node.py` 내부에 DB 제어 로직을 삽입하여 출발 시점과 도착 시점의 배송 이력을 기록(Insert/Update)합니다.
* **검증 (체크포인트 4)**: 시나리오 종료 후 터미널에서 DB를 조회했을 때 배송 내역이 정상적으로 기록되어 있는지 확인합니다.

- [ ] **Step 4**: `2D Nav Goal`을 이용한 Navigation 기본 자율주행 동작 확인
- [ ] **Step 5**: 비전 노드 및 경로 제어 노드 통합 구동 (모듈 10)
- [ ] **Step 6**: QR 인식 ➡️ 자동 좌표 하달 ➡️ 자율 이동 연동 테스트
- [ ] **Step 7**: SQLite3 환경 구축 및 DB 테이블 생성 (모듈 11)
- [ ] **Step 8**: 주행 노드에 DB 연동 로직 추가 및 최종 기록 확인
