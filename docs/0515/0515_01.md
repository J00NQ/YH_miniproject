# 미니프로젝트 2차 단계: 다중 QR 자율주행 테스트 가이드 (2026.05.15)

본 문서는 새롭게 구축된 병원 월드(`turtlebot3_hospital_sim`)에서 **START QR**과 **ARRIVAL QR**을 활용한 자율주행 테스트를 VMWare 환경에서 진행하기 위한 가이드입니다.

---

## 1. 개요
기존 단일 QR 코드 방식에서 벗어나, 로봇이 시작 지점에서 목적지와 임무를 부여받고(`START` QR), 도착 지점에서 임무 완료를 확인하는(`ARRIVAL` QR) 시나리오로 고도화되었습니다. QR 코드의 크기도 터틀봇 스케일에 맞게 기존 대비 **1/4 크기로 축소**되었습니다.

## 2. 테스트 준비 (VMWare 내부 실행)

### 2.1 파이썬 패키지 설치
QR 코드를 렌더링하기 위해 `qrcode` 패키지와 `pillow` 라이브러리가 필요합니다. VMWare 터미널에서 아래 명령어를 실행하여 설치합니다.
```bash
pip install qrcode[pil]
```

### 2.2 QR 코드 가제보 모델 생성
코드 작성용 환경에서 작성된 `generate_qr_models.py` 스크립트를 VMWare 환경에서 실행하여 가제보 모델을 자동 생성합니다.
```bash
cd ~/catkin_ws/src/qr_logistics_robot/scripts
python3 generate_qr_models.py
```
> **정상 결과**: `models/qr_start` 및 `models/qr_arrival` 폴더가 생성되고 1/4 크기(0.2 x 0.2)의 SDF 모델과 QR 이미지가 렌더링됩니다.

---

## 3. 월드 구성 및 QR 코드 배치

### 3.1 병원 월드 실행
가벼운 병원 월드 론치 파일을 실행합니다.
```bash
roslaunch qr_logistics_robot hospital_world.launch
```

### 3.2 QR 코드 수동 배치 (가제보 GUI)
가제보 상단 메뉴의 **Insert** 탭에서 생성된 QR 코드를 아래 위치에 배치합니다.
1. **qr_start**: 로봇의 초기 위치 바로 앞 (로봇 카메라 시야에 들어오게 배치)
2. **qr_arrival**: Navigation의 목적지로 설정된 책상3 근처 (좌표: `X=2.5, Y=-1.0` 근방의 벽면 또는 임의의 구조물 앞)

### 3.3 맵 저장 (필요 시 최초 1회)
병원 월드의 `hospital_map.yaml`이 없다면 SLAM을 통해 맵을 생성하고 저장합니다.
```bash
roslaunch turtlebot3_slam turtlebot3_slam.launch slam_methods:=gmapping
# (텔레오프 등으로 맵 전체 스캔 후 저장)
rosrun map_server map_saver -f ~/catkin_ws/src/qr_logistics_robot/maps/hospital_map
```

---

## 4. 자율주행 통합 테스트

월드와 QR 코드가 모두 배치된 상태에서 다음 노드들을 순차적으로 실행합니다.

**터미널 1: Navigation 스택 실행**
```bash
roslaunch turtlebot3_navigation turtlebot3_navigation.launch map_file:=$HOME/catkin_ws/src/qr_logistics_robot/maps/hospital_map.yaml
```
> rviz가 켜지면 `2D Pose Estimate`를 사용해 로봇의 초기 위치를 잡아줍니다.

**터미널 2: 비전 인식 노드 실행**
```bash
rosrun qr_logistics_robot vision_recognizer_node.py
```
> `START` QR 코드를 인식하면 터미널에 임무 하달 메시지가 뜹니다.

**터미널 3: 경로 계획 노드 실행**
```bash
rosrun qr_logistics_robot path_planner_node.py
```

### 🎯 시나리오 검증 포인트
1. 로봇이 시작점에서 `START` QR을 인식하고, `책상3(으)로 이동` 로그를 띄우는지 확인.
2. 로봇이 목적지(`X=2.5, Y=-1.0`)로 자동 이동하는지 확인.
3. 도착 직후 로봇의 카메라 시야에 `ARRIVAL` QR이 들어왔을 때, `배송 완료! 목적지 QR 인식을 성공했습니다.` 로그를 띄우고 대기 상태로 정상 전환되는지 확인.
