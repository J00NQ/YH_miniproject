# 5월 15일 작업 3: 시작 지점 QR 기반 자율주행 테스트 가이드

## 1. 개요
목적지(도착 지점) 좌표의 세밀한 조정이 필요하므로, 현재 단계에서는 **도착 지점 QR 코드 인식 로직을 보류하고 로봇이 START QR 코드를 인식하여 올바른 좌표로 주행하는지 검증하는 데 집중**합니다.

본 테스트의 목적은 새로운 병원 월드 맵 위에서 로봇이 비전 인식 결과를 바탕으로 `MoveBase` 네비게이션 목표를 제대로 수신하고 장애물을 피해 스스로 주행하는지 확인하는 것입니다.

---

## 2. 테스트 준비 상태 확인
테스트를 시작하기 전 아래 상태가 완료되어 있어야 합니다.
1. 가제보(Gazebo)에서 `hospital_world.launch`가 구동되어 병원 맵이 열려 있어야 합니다.
2. 로봇 바로 정면(약 0.5m 앞)에 **START QR**(`qr_start` 모델)이 카메라를 바라보도록 배치되어 있어야 합니다. (도착 지점의 ARRIVAL QR은 현재 배치하지 않아도 무방합니다.)

---

## 3. 자율주행 테스트 실행 순서

각각 새로운 터미널을 열고 다음 명령어들을 순서대로 실행합니다.

### 3.1 터미널 1: 네비게이션 스택 구동
저장해 둔 병원 맵을 기반으로 경로를 탐색하는 핵심 노드들을 실행합니다.
```bash
roslaunch turtlebot3_navigation turtlebot3_navigation.launch map_file:=$HOME/catkin_ws/src/qr_logistics_robot/maps/hospital_map.yaml
```
> **[중요 - 초기 위치 설정]**
> RViz 창이 열리면, 상단의 `2D Pose Estimate` 버튼을 클릭한 뒤 지도 상에서 **가제보의 실제 로봇 위치 및 바라보는 방향과 동일하게 화살표를 드래그**하여 현재 위치를 맞춰주세요.

### 3.2 터미널 2: 비전 인식 노드 구동
로봇 카메라를 켜고 정면의 START QR을 인식하여 좌표를 해독합니다.
```bash
rosrun qr_logistics_robot vision_recognizer_node.py
```
> **성공 확인**: 터미널에 `[배송 시작 QR 감지!] 임무: 책상3(으)로 이동` 로그가 정상적으로 출력되는지 확인합니다. (OpenCV 창에도 `START` 텍스트가 표시되어야 합니다.)

### 3.3 터미널 3: 경로 계획 및 주행 제어 노드 구동
비전 노드에서 퍼블리시한 좌표를 받아 Navigation(move_base) 서버로 주행 명령을 하달합니다.
```bash
rosrun qr_logistics_robot path_planner_node.py
```
> **성공 확인**: 터미널에 `>>> [책상3(으)로 이동] 임무를 시작합니다! (목표 좌표: X=2.5, Y=-1.0)` 와 `--- 주행 목표(Goal) 실제 전송 완료! ---` 로그가 표시되어야 합니다.

---

## 4. 주행 검증 및 체크리스트

명령이 제대로 하달되었다면, 로봇이 스스로 경로를 계산하고 주행을 시작합니다. RViz와 가제보 화면을 동시에 띄워두고 아래 사항들을 점검하세요.

- [ ] **초기 경로 생성**: RViz 상에서 초록색 선(Global Plan)이 목표 지점(X=2.5, Y=-1.0)까지 장애물을 피해서 올바르게 그려지는가?
- [ ] **장애물 회피**: 병원 복도나 방의 벽면, 문틀 등에 부딪히지 않고 부드럽게 회전하여 빠져나가는가?
- [ ] **목표 지점 도달**: 로봇이 설정된 목표 좌표 부근에 정확히 정지하는가?
- [ ] **좌표 개선점 파악**: 로봇이 도착한 좌표(X=2.5, Y=-1.0)가 의도한 책상의 위치와 잘 맞는지, 혹은 벽에 너무 가까워서 도달 실패(Aborted)가 뜨는지 확인합니다. (이후 좌표 개선의 기준이 됩니다.)

---

## 5. 좌표 튜닝 팁
주행 테스트 결과, 해당 목적지 좌표가 벽 안쪽이거나 너무 좁은 구역이라 Navigation이 실패하는 경우, 아래 절차로 손쉽게 좌표를 변경할 수 있습니다.

1. `scripts/generate_qr_models.py` 파일 열기
2. `qr_data_list`의 `START` 항목 내 `"target": {"x": 2.5, "y": -1.0, "theta": 0.0}` 값을 안전한 복도 쪽 좌표로 변경
3. 파이썬 스크립트 재실행(`python3 generate_qr_models.py`)하여 QR 모델 덮어쓰기
4. 가제보 내의 QR 모델 삭제 후 새로고침된 모델로 다시 Insert 후 재테스트
