# 5월 15일 작업 2: 병원 월드에 QR 코드 모델 적용 및 배치 가이드

## 1. 개요
병원 월드 맵핑이 완료되었으므로, 자율주행 임무를 수행할 **START QR**(배달 시작 및 좌표 하달)과 **ARRIVAL QR**(목적지 도착 확인) 모델을 생성하고 월드 내에 배치하는 과정을 가이드합니다. 

QR 코드의 크기는 향후 카메라 인식 테스트 결과에 따라 유동적으로 조정할 예정이므로, 현재는 임시로 1/4 크기(0.2 x 0.2)로 생성하여 맵의 적절한 위치에 수동 배치하는 방법을 다룹니다.

---

## 2. QR 코드 모델 자동 생성

미리 작성해 둔 파이썬 스크립트를 실행하여, AIHub 서빙로봇 데이터 규격에 맞춘 QR 이미지와 가제보 모델(SDF) 파일을 생성합니다.

### 2.1 스크립트 실행
VMWare 우분투 터미널을 열고 아래 명령어를 실행합니다.
```bash
# 1. 패키지 경로로 이동
cd ~/catkin_ws/src/qr_logistics_robot/scripts

# 2. qrcode 패키지가 없다면 설치 (최초 1회)
pip install qrcode[pil]

# 3. 모델 생성 스크립트 실행
python3 generate_qr_models.py
```

### 2.2 생성 결과 확인
실행이 완료되면 `models` 폴더 아래에 다음 두 개의 폴더가 생성됩니다.
- `models/qr_start/`: 로봇의 초기 위치에 둘 시작 QR (목표 좌표 X=2.5, Y=-1.0 포함)
- `models/qr_arrival/`: 목적지에 둘 도착 확인용 QR

---

## 3. Gazebo 월드에 QR 코드 삽입 및 배치

Gazebo의 GUI를 활용하여 생성된 QR 모델을 직관적으로 맵 위에 배치합니다.

### 3.1 병원 월드 실행
```bash
roslaunch qr_logistics_robot hospital_world.launch
```

### 3.2 모델 삽입 (Insert)
1. Gazebo 창의 좌측 상단 패널에서 **[Insert]** 탭을 클릭합니다.
2. 폴더 목록 중에서 우리가 만든 모델 디렉토리(보통 `qr_logistics_robot` 경로)를 찾아 펼칩니다.
3. 목록에서 **`qr_start`**와 **`qr_arrival`** 모델을 확인할 수 있습니다.

### 3.3 추천 배치 위치 가이드
모델 이름을 클릭한 뒤, 마우스를 3D 뷰어 창으로 가져가면 모델이 따라다닙니다. 클릭하여 맵 위에 내려놓으세요.

* **START QR (`qr_start`) 배치 위치**
  - **위치**: 로봇이 스폰된 위치(`X=0.0, Y=0.0`)의 **바로 앞 (약 0.5m ~ 1m 거리)**
  - **이유**: 로봇이 실행되자마자 카메라 시야에 QR 코드가 들어와야 즉시 임무(목적지 좌표)를 인식하고 출발할 수 있습니다. 로봇이 바라보는 방향(정면)에 맞춰 세워주세요.

* **ARRIVAL QR (`qr_arrival`) 배치 위치**
  - **위치**: 병원 맵 내부의 특정 방이나 복도 끝 (START QR에 입력된 목표 좌표 `X=2.5, Y=-1.0` 근처의 벽면 앞)
  - **이유**: 로봇이 Navigation을 통해 `X=2.5, Y=-1.0` 좌표에 도착했을 때, 카메라가 정면을 바라보는 곳에 ARRIVAL QR이 있어야 "배달 완료" 처리가 정상적으로 이루어집니다.

### 3.4 크기 및 위치 미세 조정
- 상단 툴바의 **[Translate Mode (이동 화살표 아이콘)]**를 클릭하여 모델을 정확한 위치로 드래그합니다.
- 상단 툴바의 **[Rotate Mode (회전 아이콘)]**를 클릭하여 QR 코드가 로봇 카메라를 정면으로 바라보도록 각도를 맞춥니다.
- **크기(Scale)**: 현재 스크립트에서 `0.2 x 0.2`로 축소해 두었습니다. 만약 테스트 후 너무 작아서 인식이 안 되거나, 너무 크다면 추후 `generate_qr_models.py` 파일 내의 `<size>0.2 0.2 0.01</size>` 수치를 변경하고 스크립트를 재실행하면 일괄 적용됩니다.

## 4. 팁: 월드 파일에 영구 저장하기
수동 배치가 성공적이라면 매번 Insert 할 필요 없이 해당 상태를 저장할 수 있습니다.
1. QR 배치가 완료된 상태에서 Gazebo 상단 메뉴의 **[File] -> [Save World As]** 클릭
2. `~/catkin_ws/src/qr_logistics_robot/worlds/hospital.world` 경로에 덮어쓰기 저장
3. 이후 런치 파일을 실행하면 QR 코드가 항상 그 자리에 존재하게 됩니다.
