# 미니프로젝트 2회차 (2026.05.08) - 비전 인식 모듈 고도화

## 1. 개요
기존 `vision_recognizer_node.py` 파일에 미니프로젝트 2회차 요구사항(OpenCV 영상처리)을 반영하여 수정하였습니다.
단순히 QR 코드를 해독하는 것을 넘어, 조명 및 잡음 등 실제 환경 변수를 고려한 **이미지 전처리 로직**과 **PnP 알고리즘을 통한 물리적 거리 계산** 기능이 추가되었습니다.

## 2. 주요 수정 내역 (`vision_recognizer_node.py`)

### 2.1 이미지 전처리 및 기능 안정화 (중급 요건)
- `cv2.cvtColor`: 컬러 이미지를 흑백으로 변환하여 `pyzbar` 디코딩 속도 향상.
- `cv2.GaussianBlur`: 실제 카메라 센서 환경에서 발생할 수 있는 노이즈를 제거하여 오인식 방지.
- `cv2.createCLAHE` (대비 제한 적응형 히스토그램 평활화): 역광이나 부분적인 그림자 환경에서도 QR코드의 대비를 뚜렷하게 만들어 인식률을 극대화.

### 2.2 Navigation 기반 목적지까지의 경로 거리 시각화 (응용)
- 단순한 QR 코드까지의 직선 거리가 아닌, 실제 로봇이 주행해야 하는 목적지까지의 경로 길이를 파악합니다.
- `nav_msgs/Path` 토픽(`/move_base/NavfnROS/plan` 등)을 구독하여 실시간 글로벌 경로 길이를 합산하고, 로봇이 도착지까지 남은 실제 주행 거리(m)를 도출합니다.
### 2.3 실시간 시각화 및 FPS 측정 (초급/중급 요건)
- `cv2.imshow`: 로봇의 시야를 보여주는 윈도우 창 출력.
- `cv2.polylines` & `cv2.circle`: QR 코드 영역 테두리와 정중앙 좌표 표시.
- `cv2.putText`: 목적지 텍스트, 초당 프레임 수(FPS), 목적지까지의 주행 경로 남은 거리(m)를 영상 좌측 상단에 실시간 오버레이.

## 3. 실행 방법 (테스트)
```bash
# 1. 시뮬레이션 환경 실행
roslaunch qr_logistics_robot logistics_world.launch

# 2. SLAM 네비게이션 런치 파일 실행
roslaunch turtlebot3_navigation turtlebot3_navigation.launch map_file:=$HOME/catkin_ws/src/qr_logistics_robot/maps/logistics_map.yaml

# 3. 업데이트된 비전 인식 노드 실행
rosrun qr_logistics_robot vision_recognizer_node.py

# 4. 경로 계획 알고리즘 노드 실행
rosrun qr_logistics_robot path_planner_node.py
```
- 영상 화면이 뜨고 QR 코드가 포착되면 초록색 사각형과 함께 실제 거리(m)가 표시됩니다.
