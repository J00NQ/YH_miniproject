# 미니프로젝트 2회차 (2026.05.08) - turtlebot3_hospital_sim 월드 추가

## 1. 개요
VMWare 환경의 리소스 한계를 고려하여 경량 오픈소스 월드인 `turtlebot3_hospital_sim`을 추가합니다.
기존 `logistics.world` 단일 환경에서 벗어나, 병원 복도·방 구조의 다양한 공간에서 QR 인식 및 자율주행 노드의 범용성을 검증하는 것이 목적입니다.

## 3. 설치 과정

### 3.1 저장소 클론
```bash
cd ~/catkin_ws/src
git clone https://github.com/Gastd/turtlebot3_hospital_sim.git
```

### 3.2 의존성 설치
```bash
cd ~/catkin_ws
rosdep install --from-paths src/turtlebot3_hospital_sim --ignore-src -r -y
```

### 3.3 빌드
```bash
catkin_make
source devel/setup.bash
```

### 3.4 TurtleBot3 모델 환경변수 설정
현재 프로젝트(`logistics_world.launch`)와 동일하게 `waffle_pi`를 사용합니다.
```bash
export TURTLEBOT3_MODEL=waffle_pi
```
매 터미널 세션마다 설정하지 않으려면 `~/.bashrc`에 추가합니다.
```bash
echo "export TURTLEBOT3_MODEL=waffle_pi" >> ~/.bashrc
source ~/.bashrc
```

## 4. 실행 방법

### 4.1 Hospital 월드 단독 실행
```bash
roslaunch turtlebot3_hospital_sim turtles_in_a_hospital.launch
```

### 4.2 기존 프로젝트 노드와 연동
Hospital 월드를 띄운 상태에서 기존 노드를 그대로 실행합니다.
카메라 토픽(`/camera/rgb/image_raw`) 및 네비게이션 인터페이스가 동일하므로 별도 수정 없이 연결됩니다.

```bash
# 터미널 1: Hospital 월드 실행
roslaunch turtlebot3_hospital_sim turtles_in_a_hospital.launch

# 터미널 2: SLAM으로 병원 맵 생성 (최초 1회)
roslaunch turtlebot3_slam turtlebot3_slam.launch slam_methods:=gmapping

# 터미널 3: 맵 저장
rosrun map_server map_saver -f ~/catkin_ws/src/qr_logistics_robot/maps/hospital_map

# 터미널 4 (맵 생성 완료 후): Navigation 실행
roslaunch turtlebot3_navigation turtlebot3_navigation.launch \
  map_file:=$HOME/catkin_ws/src/qr_logistics_robot/maps/hospital_map.yaml

# 터미널 5: 비전 인식 노드 실행
rosrun qr_logistics_robot vision_recognizer_node.py

# 터미널 6: 경로 계획 노드 실행
rosrun qr_logistics_robot path_planner_node.py
```

### 4.3 월드 전환 시 주의사항
- 맵이 다르므로 Navigation 실행 시 `map_file` 경로를 월드에 맞게 변경합니다.
- 로봇 초기 위치(`initialpose`)를 rviz에서 재설정해야 합니다.
- `last_published_data` 상태가 이전 세션에서 남아있을 수 있으므로, 노드를 재시작하면 초기화됩니다.

## 5. 기존 월드와 비교

| 항목 | logistics.world (기존) | turtlebot3_hospital_sim |
|---|---|---|
| 환경 구성 | 물류 창고, QR 코드 배치 | 병원 복도·방 구조 |
| 장애물 | 정적 박스/선반 | 벽·문·가구 등 복잡한 구조 |
| 맵 복잡도 | 낮음 | 중간 |
| VMWare 부하 | 낮음 | 중간 (멀티 로봇 사용 시 높아짐) |
| QR 코드 배치 | 기본 포함 | 별도 배치 필요 |

> VMWare 환경에서 부하가 높을 경우 Gazebo GUI를 끄고 실행합니다.
> ```bash
> roslaunch turtlebot3_hospital_sim turtles_in_a_hospital.launch gui:=false
> ```
