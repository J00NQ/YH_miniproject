### 1차 테스트 실패
#### DB 연결 오류
- 원인:
  - path_planner_node.py에서 sqlite3.connect(db_path)를 사용했을 때
    - 오류: SQLite objects created in a thread can only be used in that same thread.
- 해결:
  - sqlite3.connect(db_path, check_same_thread=False)로 수정
